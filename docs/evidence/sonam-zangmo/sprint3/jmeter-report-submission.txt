# What happened: bcrypt sign-ups on a busy CPU took over the gateway's 2 s per-attempt timeout (pkg/resilience), the identity circuit breaker opened, so logins got 503 and reports got 401 (no token).
# The one 409 shows a second problem: a Register that timed out at the gateway had in fact succeeded in identity, and the retry then found the email taken.
# Change made: sign-up and login now happen before the timed part (run.sh), so the test measures report submission only, as NFR-02 asks.
# Follow-up: pkg/resilience retries DeadlineExceeded for every RPC. Calls that create something (Register, SubmitReport, UploadPhoto) are not safe to retry after a timeout: a retry can fail with 409 or create a duplicate. Proposed card: retry those only on Unavailable.
